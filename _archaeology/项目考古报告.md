## 二、API 面还原（route-to-openapi 方法 · C# 适配）

技能脚本原生只支持 Flask/FastAPI/Express/Gin，本次为 C# ASP.NET WebAPI（`[RoutePrefix]`+`[Route]`+`[HttpGet/Post]`）编写了适配扫描器。

**成果**：扫描出 **298 个端点实现 → 131 条唯一 API 路径**，生成标准 OpenAPI 3.0.3 文件 `PPServerSeamless-API.openapi.json`（可直接导入 Swagger UI / Redoc / Apifox）。

## 三、领域术语表（domain-glossary）

已产出 `UBIQUITOUS_LANGUAGE.md`，四大领域 30 个术语，要点：

- **钱包域**：Seamless/Transfer 两种钱包模式的严格区分；回调五元组
- **会话域**：mgckey（会话令牌）、doInit/doSpin/doCollect、index/counter 防重放
- **逻辑域**：GameLogic、PayoutPool（奖池调节）、Chipset（按币种筹码档位）、FRB
- **集群域**：godgaming ActorSystem、六类节点角色、GITProtocol 枢纽

**标记的 4 处歧义**：
1. `Withdraw/Deposit` 在回调语境 = 扣款/派款，与日常语义相反（最高危歧义）
2. `symbol` 是游戏代号不是图标
3. `User` 指玩家而非操作员
4. `GameProviders` 枚举各方案取值漂移（COUNT=1/6/9）
